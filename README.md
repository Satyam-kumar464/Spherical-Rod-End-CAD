## 📌 Overview

This project presents the 3D CAD modelling of a **Spherical Rod End**, commonly known as a **Heim Joint** or **Rose Joint**.

The component provides a pivoting connection between mechanical members while allowing angular misalignment and transmitting loads through the joint.

The model was created in **SolidWorks**, with emphasis on mechanical geometry, threaded connections, spherical articulation, and manufacturable component design.

---

## ⚙️ Working Principle

A spherical rod end provides a pivoting connection between a threaded rod or linkage and another mechanical component.

The spherical bearing interface allows the connected members to articulate relative to each other while maintaining the mechanical connection.

The threaded shank provides a means of connecting the rod end to a linkage or adjustable rod.

### Main functions

- Allows angular misalignment between connected members
- Provides rotational articulation
- Transmits axial and radial loads
- Provides a threaded connection for adjustment
- Provides a compact mechanical linkage connection

The CAD model includes:
